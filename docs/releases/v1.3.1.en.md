# Aquarius V1.3.1 Release Notes

Release date: 2026-10-26  
Download: `Aquarius-v1.3.1-macOS.zip`  
App name: `Aquarius.app`

The complete marketing version is `1.3.1`. Build `0007` is an independent, globally increasing release-build sequence and is not appended to the version or App name.

## Changes

- Fixed a launch failure affecting some V1.3.0 installations.
- V1.3.0 users must manually install and replace the App with this release once; Sparkle checks work again afterward.
- Keep the stable App name `Aquarius.app`, with version `1.3.1` and Build `0007` stored separately.

## Requirements And Usage Boundaries

- Apple silicon (arm64), macOS 14.0 or later.
- V1.2.1 and earlier must first install an updater-enabled version manually. V1.3.0 users must also install this release manually because an app that fails to launch cannot run its in-app updater.
- Installing an update exits and relaunches Aquarius. Finish active media processing first; updates are held while conflicting work is active.
- Direct source-file writing modifies the original MOV / QuickTime file. Back up originals first; this operation requires an existing writable TMCD track.
- MediaInfo CLI is an optional external dependency and is not bundled.

## Install

1. Download and unzip `Aquarius-v1.3.1-macOS.zip` from the [GitHub Release](https://github.com/LexTheAries2209/Aquarius/releases/tag/v1.3.1).
2. Move `Aquarius.app` to Applications or your local tools folder, replacing the old copy.
3. V1.3.0 users must complete this step manually once; later updates can use Sparkle from Settings.
