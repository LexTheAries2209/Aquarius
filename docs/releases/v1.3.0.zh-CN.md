# Aquarius V1.3.0 发布说明

发布日期：2026-10-26  
下载：`Aquarius-v1.3.0-macOS.zip`  
App 名称：`Aquarius.app`

完整版本号为 `1.3.0`；Build `0006` 是独立、全局递增的发布构建序号，不拼接到版本号或 App 名称中。

## 本次更新

- 可在设置中手动检查更新，也可选择启动时检查；更新清单和下载包均须通过 Sparkle EdDSA 签名验证。
- OCR 样本区域的高度可通过分隔处直接调整；预览、样本列表和媒体侧栏保持清晰分区。
- App 名称固定为 `Aquarius.app`，完整版本为 `1.3.0`，独立发布构建号为 `0006`。

## 系统要求与使用边界

- Apple silicon（arm64），macOS 14.0 或更新版本。
- V1.2.1 及更早版本不含更新器，需从 GitHub Releases 手动安装 `Aquarius.app`；完成首次升级后才可使用 Sparkle。
- 安装更新会退出并重启 Aquarius。请先结束正在进行的媒体处理；活动任务期间不会开始或继续更新。
- 直接写入源文件会修改原始 MOV / QuickTime 文件。操作前请备份；此操作仅适用于已有可写 TMCD 轨道的文件。
- MediaInfo CLI 是可选外部依赖，不随 App 提供。
