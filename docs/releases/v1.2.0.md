# Aquarius V1.2.0

Release date / 发布日期：2026-10-25

Download / 下载：`Aquarius-v1.2.0-macOS.zip`

This release packages the changes on `main` since V1.1.1. It uses Xcode `Version = 1.2` and `Build = 0`, producing the public label and app display name `Aquarius V1.2.0`.

## 中文

Aquarius V1.2.0 改进烧录时间码识别与素材复核流程，并调整了视频预览、样本列表和项目设置的操作方式。

### 本次更新

- 改进时间码识别的 ROI 边缘处理、完整标签校验和采样结果排序；时间码帧率判断会综合整段素材证据。
- 支持单帧前进/后退，并可按住方向键连续逐帧浏览。
- OCR 样本区可调整高度；样片菜单和识别字段默认值可在项目设置中调整。
- 可在项目设置中控制时间码诊断详情和元数据编辑区的显示。
- 项目最低系统版本为 macOS 14.0，发布构建面向 Apple silicon。

### 使用边界

- Aquarius 仍使用 Apple Vision，不包含 PP-OCR、ONNX Runtime 或 Core ML OCR 模型。
- OCR 结果仍需结合画面清晰度和 ROI 位置检查；关键剪辑元数据请人工复核。
- 直接写入源文件会修改原始 MOV / QuickTime 文件。操作前请备份；此模式仅适用于已有可写 TMCD 轨道的文件。
- MediaInfo CLI 仍为可选外部依赖，不随 App 提供。

### 验证状态

- 本地构建、回归脚本、归档 App 启动和独立归档源码构建结果将在发布包生成后补录。
- macOS 最低版本：14.0；Release 架构：Apple silicon（arm64）。
- App 将以未签名、未经公证方式分发；macOS 可能要求用户在 Finder 或“隐私与安全性”中确认首次打开。

### 安装

1. 从 GitHub Release 下载并解压 `Aquarius-v1.2.0-macOS.zip`。
2. 将 `Aquarius V1.2.0.app` 移至“应用程序”或本地工具目录。
3. 首次打开时，如 macOS 阻止启动，请在 Finder 中右键选择“打开”，或在“系统设置 > 隐私与安全性”中确认。

## English

Aquarius V1.2.0 improves burned-in timecode recognition and review workflows, with refinements to video preview, OCR samples, and Project Settings.

### Changes

- Improved timecode ROI edge handling, complete-label validation, and sample ordering. Source-rate ranking now considers evidence across the clip.
- Added single-frame backward/forward stepping and continuous frame stepping while holding an arrow key.
- Made the OCR sample area resizable and added Project Settings for the sample menu and default recognition fields.
- Added controls for timecode diagnostic details and metadata editor visibility.
- Raised the minimum macOS version to 14.0; Release builds target Apple silicon.

### Usage Boundaries

- Apple Vision remains the production recognizer. PP-OCR, ONNX Runtime, and Core ML OCR models are not bundled.
- OCR results still depend on image clarity and ROI placement. Review critical editorial metadata manually.
- Direct source-file writing modifies the original MOV / QuickTime file. Back up originals first; this mode requires an existing writable TMCD track.
- MediaInfo CLI remains an optional external dependency and is not bundled.

### Verification Status

- Local build, regression scripts, archived-app launch, and independent archived-source build results will be recorded after the release package is produced.
- Minimum macOS version: 14.0. Release architecture: Apple silicon (arm64).
- The app will be distributed unsigned and without notarization. macOS may require confirmation through Finder or Privacy & Security on first launch.

### Install

1. Download and unzip `Aquarius-v1.2.0-macOS.zip` from the GitHub Release.
2. Move `Aquarius V1.2.0.app` to Applications or your local tools folder.
3. If macOS blocks the first launch, right-click the app in Finder and choose Open, or approve it in System Settings > Privacy & Security.
