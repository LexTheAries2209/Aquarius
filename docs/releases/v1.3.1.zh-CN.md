# Aquarius V1.3.1 发布说明

发布日期：2026-10-26  
下载：`Aquarius-v1.3.1-macOS.zip`  
App 名称：`Aquarius.app`

完整版本号为 `1.3.1`；Build `0007` 是独立、全局递增的发布构建序号，不拼接到版本号或 App 名称中。

## 本次更新

- 修复 V1.3.0 在部分 Mac 上无法启动的问题。
- V1.3.0 用户需从 GitHub Releases 手动安装并替换为本版一次；之后可继续使用 Sparkle 检查更新。
- 保持 App 名称 `Aquarius.app`，版本号 `1.3.1` 与 Build `0007` 分别记录。

## 系统要求与使用边界

- Apple silicon（arm64），macOS 14.0 或更新版本。
- V1.2.1 及更早版本需先手动安装含更新器的版本；V1.3.0 用户也必须手动安装本版，因旧版启动失败时无法运行应用内更新器。
- 安装更新会退出并重启 Aquarius。请先结束正在进行的媒体处理；活动任务期间不会开始或继续更新。
- 直接写入源文件会修改原始 MOV / QuickTime 文件。操作前请备份；此操作仅适用于已有可写 TMCD 轨道的文件。
- MediaInfo CLI 是可选外部依赖，不随 App 提供。

## 安装

1. 从 [GitHub Release](https://github.com/LexTheAries2209/Aquarius/releases/tag/v1.3.1) 下载并解压 `Aquarius-v1.3.1-macOS.zip`。
