# Aquarius V1.1.1 发布说明

发布日期：2026-07-28

下载：`Aquarius-v1.1.1-macOS.zip`

Aquarius V1.1.1 重点提升烧录画面中文件名和时间码的 OCR 稳定性。当前构建使用 `Version = 1.1`、`Build = 1`，App 显示名为 `Aquarius V1.1.1`。

## 本次更新

- 支持 `A006C001` 这类 `LDDDLDDD` 紧凑摄影机文件名；该字符串是格式示例，并非只针对单一文件名。
- 按字符位置约束常见字母/数字混淆，包括 `0/O`、`1/I/L/T`、`2/Z`、`5/S`、`6/G`、`8/B`。
- 每个 Apple Vision observation 最多读取 5 个候选，按字段格式、OCR 置信度和候选差距排序。
- 新增自适应 OCR 图像处理：ROI 放大、灰度、对比度、锐化、反色、阈值二值化和紧裁剪，并融合多个预处理版本的结果。
- 时间码在采样点读取前一帧、当前帧和后一帧，结合实际有理帧率检查帧号范围、DF/NDF 格式及连续递增关系。
- 重新校准最终置信状态。发生位置约束字符纠错或帧率存在歧义时，结果不会直接进入“可信”。
- 增加可自动运行的 OCR 回归入口和素材标注契约，覆盖 23.976、24、25、29.97 NDF/DF 与 30 fps。
- Release 构建改为仅包含 `arm64`，从 V1.1.1 起只支持 Apple silicon（M 系列芯片）。
- 更新 Aquarius App 图标。

## 识别器边界

- V1.1.1 的正式识别器仍是 Apple Vision。
- 本版没有内置 PP-OCRv6、ONNX Runtime 或 Core ML OCR 模型。
- `A00GC00T` 可以按位置约束推导为 `A006C001`，但必须进入“需复核”，不能作为高置信结果自动通过。
- 四个内置视频回归均通过；真实项目素材尚未形成完整盲测基准，因此本版不宣称已经解决所有字体、码率、缩放或叠字布局下的 OCR 错误。

## 验证状态

- OCR 解析、候选排序、自适应预处理、相邻帧时间码和置信度校准回归通过。
- 四个内置视频的文件名、卷号和起始时间码均得到预期结果，最终置信度为 `1.00`。
- Aquarius Debug、严格并发且警告视为错误、Swift 6 兼容性和 Release 构建均成功。
- 实际启动验证通过。
- 发布 App 信息：`CFBundleShortVersionString = 1.1`、`CFBundleVersion = 1`、`arm64`、macOS `13.0` 或更新版本。
- ZIP 大小：`15,786,749` 字节；SHA-256：`2a275e55e79c7228c2bbc21f9611092e40bf3ce7489ede6c512b8aea7a6d55d5`。
- App 使用 Apple Development 签名，签名在磁盘上验证有效，但不是 Developer ID 公证发行，Gatekeeper 会拒绝自动信任。

## 安装

1. 下载并解压 `Aquarius-v1.1.1-macOS.zip`。
2. 把 `Aquarius V1.1.1.app` 放到 `Applications` 或自己的工具目录。
3. 首次打开时，请在 Finder 中右键点击 App 并选择“打开”；如仍被阻止，请在“系统设置 > 隐私与安全性”中确认打开。

可选的 MediaInfo CLI 仍不包含在 App 内。未安装时 OCR、导出、复制改名和 TMCD 功能仍可使用，但当前文件元数据面板只显示基础信息。
