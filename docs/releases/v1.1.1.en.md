# Aquarius V1.1.1 Release Notes

Release date: 2026-07-28

Download: `Aquarius-v1.1.1-macOS.zip`

Aquarius V1.1.1 focuses on more reliable clip-name and timecode OCR from burned-in overlays. This build uses `Version = 1.1` and `Build = 1`, so the app display name is `Aquarius V1.1.1`.

## Changes

- Added support for compact `LDDDLDDD` camera clip names such as `A006C001`. The value is a format example, not a one-off hard-coded name.
- Added position-constrained letter/digit correction for `0/O`, `1/I/L/T`, `2/Z`, `5/S`, `6/G`, and `8/B` confusions.
- Read up to five candidates per Apple Vision observation and rank them by field format, OCR confidence, and candidate margin.
- Added adaptive OCR image processing: ROI scaling, grayscale, contrast, sharpening, inversion, threshold binarization, and tighter crops, with evidence fused across variants.
- Read the previous, current, and next frame at each timecode sample and validate frame ranges, DF/NDF syntax, and continuity using the rational frame rate.
- Recalibrated final confidence. Position-corrected text or ambiguous timecode rates cannot be marked trusted automatically.
- Added an automated OCR regression entry point and a benchmark sample contract covering 23.976, 24, 25, 29.97 NDF/DF, and 30 fps.
- Changed Release builds to `arm64` only. V1.1.1 and later support Apple silicon (M-series) Macs only.
- Updated the Aquarius app icon.

## Recognizer Boundary

- Apple Vision remains the production recognizer in V1.1.1.
- This release does not bundle PP-OCRv6, ONNX Runtime, or a Core ML OCR model.
- `A00GC00T` can be normalized to `A006C001` by position constraints, but the result must remain review-required rather than becoming a high-confidence automatic match.
- All four bundled-video regressions pass. Production footage has not yet been collected into a complete blind benchmark, so this release does not claim to solve every font, bitrate, scale, or overlay-layout OCR failure.

## Verification Status

- OCR parsing, candidate ranking, adaptive preprocessing, adjacent-frame timecode, and confidence calibration regressions passed.
- All four bundled videos produced their expected clip name, reel, and start timecode with final confidence `1.00`.
- Aquarius Debug, strict-concurrency with Swift warnings as errors, Swift 6 compatibility, and Release builds succeeded.
- The built Release app launched successfully.
- Release app metadata: `CFBundleShortVersionString = 1.1`, `CFBundleVersion = 1`, `arm64`, macOS `13.0` or later.

## Install

1. Download and unzip `Aquarius-v1.1.1-macOS.zip`.
2. Move `Aquarius V1.1.1.app` to `Applications` or your own tools folder.
3. On first launch, right-click the app in Finder and choose Open. If it is still blocked, allow it from System Settings > Privacy & Security.

The optional MediaInfo CLI remains external to the app. OCR, export, copy/rename, and TMCD functions still work without it, but the Current File metadata panel only shows basic information.
