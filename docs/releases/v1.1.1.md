# Aquarius V1.1.1

Release date / 发布日期：2026-07-28

Download / 下载：`Aquarius-v1.1.1-macOS.zip`

## 中文

Aquarius V1.1.1 重点提升烧录画面中文件名和时间码的 OCR 稳定性。当前构建为 `Version = 1.1`、`Build = 1`，App 显示名为 `Aquarius V1.1.1`。

### 本次更新

- 支持 `A006C001` 这类 `LDDDLDDD` 紧凑摄影机文件名，并按字符位置处理 `0/O`、`1/I/L/T`、`2/Z`、`5/S`、`6/G`、`8/B` 混淆。
- 每个 Apple Vision observation 最多读取 5 个候选，并按字段规则排序。
- 新增 ROI 放大、灰度、对比度、锐化、反色、阈值二值化和紧裁剪等自适应图像处理。
- 时间码通过相邻三帧、实际有理帧率、DF/NDF 及连续性联合校验。
- 发生位置约束纠错或帧率歧义时强制进入“需复核”，避免高置信错误。
- 增加 OCR 回归入口和真实素材标注契约。
- Release 改为仅含 `arm64`，从本版起只支持 Apple silicon（M 系列芯片）及 macOS `13.0` 或更新版本。
- 更新 Aquarius App 图标。

### 识别与验证边界

- 本版仍使用 Apple Vision，没有内置 PP-OCRv6、ONNX Runtime 或 Core ML OCR 模型。
- `A00GC00T` 可以推导为 `A006C001`，但不能作为“可信”结果自动通过。
- OCR 回归、四个内置视频、Debug、严格并发/警告、Swift 6 兼容、Release 构建和实际启动验证均通过。
- 发布 ZIP 为 `15,786,749` 字节，SHA-256：`2a275e55e79c7228c2bbc21f9611092e40bf3ce7489ede6c512b8aea7a6d55d5`。
- 真实项目素材尚未形成完整盲测基准，因此仍需人工复核关键元数据。
- App 使用 Apple Development 签名且在磁盘上验证有效，但不是 Developer ID 公证发行；Gatekeeper 可能要求 Finder 右键“打开”或在“隐私与安全性”中确认。

## English

Aquarius V1.1.1 focuses on more reliable clip-name and timecode OCR from burned-in overlays. This build uses `Version = 1.1` and `Build = 1`, producing the display name `Aquarius V1.1.1`.

### Changes

- Added compact `LDDDLDDD` camera clip names such as `A006C001`, with position-constrained correction for common letter/digit confusions.
- Read up to five Apple Vision candidates per observation and rank them with field-specific rules.
- Added adaptive ROI scaling, grayscale, contrast, sharpening, inversion, threshold binarization, and tighter crop variants.
- Validated timecode with adjacent frames, rational frame rates, DF/NDF syntax, and continuity.
- Forced corrected or rate-ambiguous results into review instead of allowing high-confidence automatic acceptance.
- Added an OCR regression entry point and a production sample annotation contract.
- Changed Release builds to `arm64` only for Apple silicon (M-series) Macs running macOS `13.0` or later.
- Updated the Aquarius app icon.

### Recognition And Verification Boundary

- Apple Vision remains the production recognizer; PP-OCRv6, ONNX Runtime, and Core ML OCR models are not bundled.
- `A00GC00T` may normalize to `A006C001`, but it cannot automatically become trusted.
- OCR regressions, four bundled videos, Debug, strict concurrency/warnings, Swift 6 compatibility, Release build, and launch verification passed.
- The release ZIP is `15,786,749` bytes with SHA-256 `2a275e55e79c7228c2bbc21f9611092e40bf3ce7489ede6c512b8aea7a6d55d5`.
- Production footage has not yet been collected into a complete blind benchmark, so critical metadata still requires review.
- The app is Apple Development signed and validates on disk, but it is not a notarized Developer ID distribution. Gatekeeper may require Finder > Open or approval in Privacy & Security.
