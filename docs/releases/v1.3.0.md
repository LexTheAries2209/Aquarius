# Aquarius V1.3.0

Release date / 发布日期：2026-10-26

Download / 下载：`Aquarius-v1.3.0-macOS.zip`  
App name / App 名称：`Aquarius.app`

Version `1.3.0` is the complete marketing version. Build `0006` is a separate, globally increasing release-build number and is not appended to the version or App name.

## 中文

Aquarius V1.3.0 首次加入 Sparkle 签名自动更新，并改为固定 App 名称、独立版本号和构建号。V1.2.1 及更早版本需要手动安装本版一次。

### 本次更新

- 可在设置中手动检查更新，也可选择启动时检查；更新清单和下载包均须通过 Sparkle EdDSA 签名验证。
- OCR 样本区域的高度可通过分隔处直接调整；保留预览、样本列表和媒体侧栏之间清晰的分隔。
- App 名称固定为 `Aquarius.app`，完整版本为 `1.3.0`，独立发布构建号为 `0006`。

### 系统要求与使用边界

- Apple silicon（arm64），macOS 14.0 或更新版本。
- 旧版 V1.2.1 及更早版本不含更新器，需从 GitHub Releases 手动安装 `Aquarius.app`；完成首次升级后才可使用 Sparkle。
- 更新安装会退出并重启 Aquarius。请先结束正在进行的媒体处理；活动任务期间不会开始或继续更新。
- 直接写入源文件会修改原始 MOV / QuickTime 文件。操作前请备份；此操作仅适用于已有可写 TMCD 轨道的文件。
- MediaInfo CLI 是可选外部依赖，不随 App 提供。

### 验证状态

- OCR parser、ROI、时间码排序及帧率连续性回归通过；测试目录 `/Users/lex./Desktop/测试小样` 的 45/45 组分析通过，包含 945 条有效 SMPTE 读数，45 组结果均要求人工复核。
- 逐帧浏览、项目设置及样本区域布局回归通过。
- 真实 Sparkle 隔离测试通过：V1.2.1 实际 Build `1` 可更新至 `0006`；安装取消、退出前取消、任务冲突、篡改清单/安装包签名和缺失清单均按预期拒绝或取消。成功安装保留测试偏好和历史。
- Release archive、严格并发（warnings-as-errors）及 Swift 6 兼容构建通过；归档源码独立 Release 构建和归档 App 启动验证通过。
- App 元数据：`CFBundleShortVersionString = 1.3.0`、`CFBundleVersion = 0006`、显示名 `Aquarius`；架构为 arm64。主程序与归档 dSYM 的 arm64 UUID 匹配。
- Sparkle 2.10.0；App bundle 的 ad-hoc 代码签名与 Sparkle EdDSA 更新签名验证通过。没有 Developer ID 签名或 Apple 公证。
- ZIP 大小：16,633,860 字节；SHA-256：`b72365a47138eb472a068ce42a7a0bc6d40b22e28bd0ce530607eb53c9b7ec6b`。

## English

Aquarius V1.3.0 introduces signed Sparkle updates and separates the stable App name from its semantic version and release Build. V1.2.1 and earlier require one manual installation of this release.

### Changes

- Check for updates manually in Settings or enable a launch-time check. Sparkle EdDSA signatures are required for both the feed and downloaded archive.
- Resize the OCR sample area directly at its divider while keeping the preview, sample list, and media sidebar clearly separated.
- Keep the App name as `Aquarius.app`, with marketing version `1.3.0` and independent release Build `0006`.

### Requirements And Usage Boundaries

- Apple silicon (arm64), macOS 14.0 or later.
- V1.2.1 and earlier do not include the updater. Manually install `Aquarius.app` from GitHub Releases once; Sparkle is available after that upgrade.
- Installing an update exits and relaunches Aquarius. Finish active media processing first; updates are held while conflicting work is active.
- Direct source-file writing modifies the original MOV / QuickTime file. Back up originals first; this operation requires an existing writable TMCD track.
- MediaInfo CLI is an optional external dependency and is not bundled.

### Verification Status

- OCR parser, ROI, timecode ordering, and frame-rate continuity regressions passed. All 45 analyses in `/Users/lex./Desktop/测试小样` passed across 945 valid SMPTE readings; all 45 analyses still require manual review.
- Frame stepping, Project Settings, and sample-panel layout regressions passed.
- Isolated real-Sparkle tests passed: a V1.2.1 client with its actual Build `1` updated to `0006`; install cancellation, quit-before-install cancellation, active-work conflicts, tampered feed/archive signatures, and a missing feed were rejected or cancelled as expected. The successful install retained fixture preferences and history.
- The Release archive, strict-concurrency build with warnings as errors, and Swift 6 compatibility build passed. The independent archived-source Release build and archived-App launch verification also passed.
- App metadata: `CFBundleShortVersionString = 1.3.0`, `CFBundleVersion = 0006`, display name `Aquarius`; architecture is arm64. The arm64 executable UUID matches the archive dSYM.
- Sparkle 2.10.0; the App's ad-hoc code signature and Sparkle EdDSA update signatures verified. No Developer ID signing or Apple notarization.
- ZIP size: 16,633,860 bytes; SHA-256: `b72365a47138eb472a068ce42a7a0bc6d40b22e28bd0ce530607eb53c9b7ec6b`.

### Install

1. Download and unzip `Aquarius-v1.3.0-macOS.zip` from the [GitHub Release](https://github.com/LexTheAries2209/Aquarius/releases/tag/v1.3.0).
2. Move `Aquarius.app` to Applications or your local tools folder.
3. V1.2.1 and earlier must install this release manually before using in-app updates.
