# Aquarius V1.3.1

发布日期 / Release date：2026-10-26  
下载 / Download：`Aquarius-v1.3.1-macOS.zip`  
App 名称 / App name：`Aquarius.app`

完整版本号为 `1.3.1`；Build `0007` 是独立、全局递增的发布构建序号，不拼接到版本号或 App 名称中。

The complete marketing version is `1.3.1`. Build `0007` is an independent, globally increasing release-build sequence and is not appended to the version or App name.

## 本次更新 / Changes

- 修复 V1.3.0 在部分 Mac 上无法启动的问题。V1.3.0 用户需从 GitHub Releases 手动安装并替换为本版一次；之后可继续使用 Sparkle 检查更新。
- Fixed a launch failure affecting some V1.3.0 installations. V1.3.0 users must manually install and replace the App with this release once; Sparkle checks work again afterward.
- App 名称保持 `Aquarius.app`；版本号 `1.3.1` 与 Build `0007` 分别记录。
- Keep the stable App name `Aquarius.app`, with version `1.3.1` and Build `0007` stored separately.

## 系统要求与使用边界 / Requirements And Usage Boundaries

- Apple silicon（arm64），macOS 14.0 或更新版本。/ Apple silicon (arm64), macOS 14.0 or later.
- V1.2.1 及更早版本需先手动安装含更新器的版本；V1.3.0 用户也必须手动安装本版，因旧版启动失败时无法运行应用内更新器。/ V1.2.1 and earlier must first install an updater-enabled version manually. V1.3.0 users must also install this release manually because an app that fails to launch cannot run its in-app updater.
- 安装更新会退出并重启 Aquarius。请先结束正在进行的媒体处理；活动任务期间不会开始或继续更新。/ Installing an update exits and relaunches Aquarius. Finish active media processing first; updates are held while conflicting work is active.
- 直接写入源文件会修改原始 MOV / QuickTime 文件，操作前请备份；仅适用于已有可写 TMCD 轨道的文件。/ Direct source-file writing modifies the original MOV / QuickTime file. Back up originals first; this operation requires an existing writable TMCD track.
- MediaInfo CLI 是可选外部依赖，不随 App 提供。/ MediaInfo CLI is optional and is not bundled.
